SECONDO apt repository

Packages for the SECONDO database, built from the current state of the main branch. Pick the repository for your Ubuntu release (22.04, 24.04, 26.04):

echo 'deb [trusted=yes] https://secondo-database.github.io/secondo/apt/ubuntu/24.04/ ./' \
  | sudo tee /etc/apt/sources.list.d/secondo.list
sudo apt-get update
sudo apt-get install secondo

The repository is not signed, hence the [trusted=yes] option.

After the installation, set up your SECONDO environment once:

/opt/secondo/bin/secondo_installer.sh
source ~/.secondorc
